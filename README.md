# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。

## 粘贴批量导入

检查员点「批量导入」，在文本框里按行粘贴「测点名 浓度」（空格、逗号、Tab 均可分隔）：

1. 点「试算」：服务端逐行解析，只返回每行将产生的状态（正常/报警或错误），**不写库、不推送**。
2. 点「确认导入」：服务端重新解析校验，整批事务入库；报警行逐行通过 WebSocket 推送。
3. 任一行测点名为空或格式错误，确认返回 400，**整批不入库**，并在 `import_batches` 表留下失败导入记录（含原文、行号、原因、操作人）。
4. viewer 看不到入口，直接访问 `#import` 会被拦回总表，接口侧返回 403。

验收：试算一笔正常一笔报警（如 `东翼-20 0.42`、`回风斜井 1.3`），确认后总表多两行且报警那笔触发推送；再试含空测点名的一批（如 `  0.50`），确认失败、总表行数不变。
