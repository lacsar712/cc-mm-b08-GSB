# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

检查员还可以在「批量导入」页粘贴多行文本（每行「测点名,浓度」，也支持空格/制表符分隔）：先**试算**只返回每行将产生的状态（不写库、不推送），再点**确认**才整批入库。试算与确认都在服务端解析、判定；任一行测点评为空则确认失败、整批不入库，并留下一条失败导入记录。旁观账号打不开导入页，接口同样返回 403。

## 端口

```bash
cd projects/12-mine-methane-shift

```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。

### 批量导入验收

4. gasman 打开「批量导入」，粘贴一笔正常（浓度 < 1）一笔报警（浓度 ≥ 1），点试算：每行显示将产生的状态，此时总表行数不变、不推送。
5. 点确认导入：总表多两行，报警那笔通过网页套接字推送到已打开的页面。
6. 再粘贴一批其中一行测点评为空，试算标错且无法确认；强行确认返回失败、整批不入库（行数不变），导入记录里留下一条失败批次。
7. viewer 打开 `/import.html` 只看到「无权访问」，试算与确认接口均返回 403。
